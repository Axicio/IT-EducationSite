    Learn React With Mini Projects

    Go from JSX basics to five shipped projects — no fluff, just building.

    About This Course

    A hands-on introduction to React that skips the theory-heavy detours and gets you building real interfaces from lesson one. You'll learn components, state, and hooks by shipping five small projects — a component library, a to-do app, a movie search app, a weather dashboard, and a mini e-commerce cart — each one reinforcing the last.

    What You'll Learn

    • Building reusable components with JSX and props
    • Managing state with useState and useEffect
    • Fetching and displaying data from a live API
    • Client-side routing with React Router
    • Deploying a finished React app

    Course Content

    • Module 1: React Fundamentals & JSX
    • Module 2: Components, Props & State
    • Module 3: Hooks in Depth
    • Module 4: Working with APIs
    • Module 5: Mini Projects & Deployment
